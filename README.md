# ShortVideoCutter

**ShortVideoCutter** — это консольное приложение на C#, предназначенное для автоматизации вырезания и объединения фрагментов из видеофайлов на основе текстового описания. Программа интегрируется с браузером для получения ссылок на скачивание, загружает видео, нарезает моменты по таймкодам и объединяет их в итоговые ролики.

## Основные возможности

- **Автоматическое получение ссылок на видео** через эмуляцию действий в браузере (открытие окон, вставка URL, нажатие клавиш, копирование ссылок).
- **Загрузка видео** по полученным ссылкам с отображением прогресса.
- **Парсинг текстового описания** сезонов, эпизодов и моментов.
- **Обработка трёх типов моментов**:
  - _Обычные_ — простое вырезание фрагмента.
  - _Проблемные_ (отмеченные `!`) — создают текстовый файл, который позже можно вручную исправить, указав корректный путь к видео.
  - _Составные_ (например, `ID1PART2GLOB5`) — автоматическое объединение нескольких фрагментов из разных эпизодов в один ролик.
- **Объединение фрагментов** с помощью FFmpeg.
- **Проверка корректности последовательности** для составных моментов.

## Технологии

- .NET (C#)
- [NReco.VideoConverter](https://www.nrecosite.com/video_converter_net.aspx) — обёртка для FFmpeg
- xUnit + Moq + FluentAssertions — для модульного тестирования
- WinAPI (user32.dll) — для эмуляции ввода с клавиатуры и мыши

## Формат входного файла

Файл с описанием должен иметь следующую структуру:

```markdown
Название*сезона*на*русском
Название*сезона*на*английском
URL*базовый
Номер*эпизода M:SS M:SS [примечание]
Номер_эпизода M:SS M:SS [примечание]

---

Название*следующего*сезона*на*русском
Название*следующего*сезона*на*английском
...
```

- Номер_эпизода может быть `-1` если это дополнительный эпизод
- `M:SS` — минуты и секунды (например, `2:30`).
- Примечание (note) используется для идентификации типа момента:
  - Если содержит `!` — момент считается проблемным.
  - Если соответствует регулярному выражению `ID(\d+)PART(\d+)(?:GLOB(\d+))?` - момент составной.
    - указывается или ID или GLOB и ID
      - В случае ID область видимости сезон
      - В случае GLOB и ID область видимости все сезоны
  - Иначе — обычный.

## Как это работает

1. **Инициализация**  
   Программа читает текстовый файл, парсит его в объекты `Season`, `Episode`, `Moment`.

2. **Получение ссылок на скачивание**  
   Для каждого эпизода:
   - Открывается новое окно браузера (Ctrl+Shift+N).
   - В адресную строку вставляется изменённый URL.
   - Имитируются нажатия F12, F5, правый клик → "Открыть в новой вкладке", копирование ссылки.
   - Полученная ссылка сохраняется в `Episode`.

3. **Загрузка видео**  
   `Downloader` скачивает видео по ссылке, если оно ещё не существует.

4. **Обработка моментов**
   - **Обычные** – сразу нарезаются с помощью FFmpeg.
   - **Проблемные** – создаётся `.txt` файл с заметкой. Пользователь может вручную добавить в этот файл путь к корректному видео, тогда момент будет исправлен при следующем запуске.
   - **Составные** – группируются по ID (или GLOB ID), проверяется корректность последовательности частей (от 1 до N без пропусков). Затем каждая часть нарезается во временную папку, и все части объединяются в один итоговый файл.

5. **Результат**  
   В папке сохранения создаются подпапки для сезонов, внутри — видео эпизодов и нарезанные моменты.
